# immich-ubuntu-install

Deploys Immich on Ubuntu via Docker Compose, using the project's official compose and env files.

## Usage

```bash
chmod +x install_immich.sh
sudo ./install_immich.sh --dry-run
sudo ./install_immich.sh
```

See the comments at the top of `install_immich.sh` for full details
(requirements, options, security guarantees, known limitations).
